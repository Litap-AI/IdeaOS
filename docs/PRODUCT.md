# IdeaOS Product Definition

## Core thesis

IdeaOS should not be another chat-with-PDF application.

The product studies the structure and evolution of ideas inside documents.

## MVP hero feature

**Idea Genome**

A transparent, explainable profile of a document covering:

- novelty
- evidence
- influence
- persuasion
- concept density
- argument depth

The initial scores are heuristic placeholders. They must be replaced with evidence-backed model pipelines as the project matures.

## Version 0.1 boundary

Build the smallest complete loop:

PDF → parsing → concept extraction → Idea Genome → dashboard.

Do not add advanced philosophy detection, longitudinal influence tracking, or multi-agent orchestration until this loop is reliable.
